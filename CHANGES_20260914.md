# OGGI implementation and audit changes on 2026 09 14

This log covers the local implementation and earlier HOG import work in this
conversation. Changes have NOT been synchronized to the Ubuntu server.

  N0/N1/etc selection; available-node listing; separate `--level all` conversion;

## New unified cluster implementation

| File | Change |
|---|---|
| `oggi.py` | Delegates cluster to the new package; required explicit gene map; legacy mcl alias retained; failed clustering exits 2 |
| `cluster_engine/__init__.py` | New package |
| `cluster_engine/cli.py` | Eight method names, input/target validation, candidate grids, round-robin budgets, independent failure records, command logs, hashes, tool probes, lock and exact-match resume |
| `cluster_engine/methods.py` | OrthoFinder, MMseqs, CD-HIT, two within-HOG refinements, weighted and sequence-only MCL adapters; exact target partition validation; self-loops; explicit unresolved genes; provenance of HOG reuse |
| `cluster_engine/data.py` | FASTA and mapping checks, string IDs, canonical partitions, shared trusted-MSA/external distances, atomic JSON and TSV outputs |
| `cluster_engine/evidence.py` | Target-specific same/different roles, positive weights, transitive contradiction quarantine, source/block/pair leakage checks, equal-block biological support |
| `cluster_engine/scoring.py` | B/R/A/Q semantics, ARI, per-gene silhouette, common-metric geometric scores, true-zero/NA separation, finite-value checks; R deliberately NA |
| `cluster_engine/report.py` | Ranked scores, statuses, conflicts, unsupported genes, manifest, candidate tables and diagnostic SVGs; ties never produce an automatic unique selected table |

Each candidate table uses `gene_ID`, `assembly_ID`, `cluster_ID`. Input genes must
appear exactly once. Candidate failures do not abort the other candidates.
Biological target meanings and experiment limitations are explicit.

The old MCL matrix helpers remain available as legacy code, but new `cluster`
does not call their asymmetric/double-identity matrix route. Missing synteny
does not become negative evidence. Tree distance remains a prior, not duplication
event resolution. No full-proteome OrthoFinder analysis starts from a family-only
FASTA. Both hybrid methods subdivide within HOGs; no cross-HOG merge is permitted.

## Selection and serialization changes

- Default scores are provisional because R has no valid implemented perturbation.
- Metrics missing for any successful candidate are omitted task-wide; weights
  are normalized once over the common metric set.
- One group, all singletons, incomplete distances: Q=NA, not fabricated quality.
- All-merged/all-singleton partitions have B=0 when independent same and
  different constraints both exist.
- Tied candidates remain in selection.json. `selected_candidate=null`,
  `selected_clusters.tsv` header only; `representative_clusters.tsv` is an
  inspection copy and does not mean a winner.
- All candidates failed/skipped: failure report remains available and CLI exits
  2. A report successfully produced with ambiguous/provisional status exits 0;
  downstream code must inspect selection.json.
- Numeric TSV missing values are `NA`, JSON missing values are null. Gene IDs
  must be read as strings; the literal ID `NA` is valid and retained.

# Follow-up audit hardening

This supplement records a later change than the historical 30-test result below.
The full Python 3.12 environment passes 36 tests with no skips. A second environment
without Biopython discovers 36 tests, skips 3, and the new strict runner correctly
returns exit code 1. The GitHub workflow was added, not executed remotely here.

- Added `.gitignore`, Ubuntu CI, strict `tests/run_tests.py`, and six release
  regression tests. No fixed test-count threshold is used.
- Supplied legacy MMseqs/CD-HIT maps must cover all parsed genes.
- TSV readers can explicitly decode numeric missing values while preserving
  literal `NA` and leading-zero IDs. Missing identifier values are rejected.
- Boolean values are rejected as score metrics.
- Missing similarity diagnostics now carry reasons in tables and SVG panels.
- Legacy DIAMOND calls use argument lists, validate and forward max-target-seqs;
  the parameter was already forwarded before this audit, so the alleged omission
  was not a confirmed bug. A compatibility helper's set accumulation was repaired.
- CD-HIT's <=10 exclusion is retained: upstream SequenceDB retains length > -l.
  The alleged off-by-one was not confirmed. No-call-site helpers are not deleted
  merely because they may be used by external scripts.

These are software checks, including mocked external adapters, not a new
biological benchmark or validation of the 401-rice analysis.
