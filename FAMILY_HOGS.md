# Recursive HOG inference for one gene family

`oggi cluster -M hog-tree` treats the supplied family as one orthogroup (OG) and
uses copied OrthoFinder code to infer hierarchical orthogroups (HOGs). It runs
gene-tree rooting, reconciliation, duplication marking, and recursive HOG
assignment against an explicitly outgroup-rooted species tree.

The computational functions are copied from the supplied OrthoFinder source,
including `GetRoot`, `GetOrthologues_from_tree`, `mark_dups_below`, and
`write_clade_v2`. The bundled code is independent of an installed OrthoFinder
executable. See [source provenance and adaptations](orthofinder_hog/README.md)
and [third-party notices](THIRD_PARTY_NOTICES.md).

## Required inputs

1. **Target family protein FASTA:** the `gene_family.fa` produced by `identify`,
   or another curated homologous family.
2. **Gene-to-assembly map:** the existing `gene_to_assembly.tsv`. Gene IDs are
   matched exactly; no species names are inferred from gene ID prefixes.
3. **Family gene tree:** IQ-TREE or FastTree Newick output containing exactly
   the target FASTA gene IDs, with finite nonnegative lengths on non-root edges.
4. **Species/assembly tree:** IQ-TREE or FastTree Newick output, including the
   BUSCO concatenation tree generated by `oggi species-tree`. Tip names must
   match assembly IDs in the map. Additional species without family genes are
   allowed. Species-tree branch lengths are optional for this method.
5. **Explicit outgroup assembly ID(s):** always required, even if the supplied
   species tree is already rooted.

Numeric FastTree support values and IQ-TREE combined support labels such as
`99.8/100` are accepted as metadata. They are not used as branch lengths or
duplication thresholds.

The family gene tree and the BUSCO species tree are separate inputs. This method
does not build the family alignment or gene tree. It does not require complete
proteomes or a pre-existing whole-proteome OrthoFinder result directory.

## Run after BUSCO species-tree inference

Replace `OUTGROUP_ASSEMBLY_ID` with an actual species-tree tip and use the
appropriate family gene-tree path:

```bash
python oggi.py cluster \
  -M hog-tree --target hog \
  -i results/MYB/gene_family.fa \
  --gene-map results/MYB/gene_to_assembly.tsv \
  --gene-tree results/MYB/family.treefile \
  --species-tree results/species_tree/05_iqtree/species_tree.treefile \
  --outgroup OUTGROUP_ASSEMBLY_ID \
  --hog-level N1 \
  -o results/MYB.hog_tree
```

`--tree` is an alias for `--species-tree`. A tree produced by FastTree can be
passed to either tree option in the same way. Multiple outgroup assemblies use
commas, for example `--outgroup outgroup_A,outgroup_B`.

The specified outgroup must correspond exactly to one side of a species-tree
edge; a complementary split is accepted even when the input Newick has an
arbitrary root. Unknown, repeated, non-monophyletic, empty, or all-species
outgroups are rejected. The input files are not modified.

## Rooting and HOG levels

The adapter first roots the species tree at the supplied outgroup. It then
assigns new, deterministic internal node names:

- `N0`: root containing all species, including outgroups.
- `N1`: ingroup root when the ingroup contains at least two species.
- Remaining nodes: preorder traversal, with the ingroup visited first.

Use `species_node_map.tsv` to inspect the exact descendant assemblies for every
node. Existing input node names or support labels are not used as HOG node IDs.
These generated labels are independent of labels in an unrelated OrthoFinder
analysis.

OrthoFinder's `GetRoot` then roots the gene tree using the rooted species-tree
topology. This handles duplicated family genes and species absent from the
family. Outgroup genes do not have to form one clade in the gene tree. If the
family has no gene from the declared outgroup, OrthoFinder uses the first
informative species-tree split represented in that family; the absence is
recorded as `outgroup_gene_count: 0` in `inference.json`.

The gene tree must be bifurcating after rooting. A three-way root representation
of an unrooted binary tree is supported. Unresolved internal gene-tree
polytomies are rejected because this copied upstream version has an ambiguous
duplication path that cannot reliably produce HOGs for all such topologies.
The adapter does not invent a binary resolution.

## What gets split

For species tree `(O,(A,B))`, consider family tree:

```text
(o,((a1,b1),(a2,b2)))
```

At `N0`, the family can remain one ancestral HOG. At `N1`, the duplication in
the ancestor of A and B yields `{a1,b1}` and `{a2,b2}`. The outgroup gene `o` is
outside the selected node and is retained as an unresolved singleton in the
flat clustering output.

By default, the copied normal HOG algorithm runs. To also enable OrthoFinder's
extra within-HOG paralogous clade splitting, add:

```bash
--split-paralogous-clades
```

This corresponds to the upstream `-y` behavior. A terminal duplication does not
automatically split every ancestral HOG. Duplication level and selected ancestor
determine the relevant groups.

All HOG levels are exported, but `--hog-level` selects exactly one level for the
clustering candidate. Combining rows from different levels would duplicate genes
and is not a valid flat partition. Suspect or out-of-scope genes are retained
once as unresolved singletons and explicitly reported.

## Outputs

The standard candidate partition is written to:

```text
RESULT/candidates/hog-tree-*/clusters.tsv
```

Its cluster IDs follow OGGI's method-neutral naming. Original HOG IDs and
memberships are in the HOG artifacts under:

```text
RESULT/candidates/hog-tree-*/hogs/RUN_ID/
├── SpeciesTree_rooted_node_labels.txt
├── GeneTree_rooted.nwk
├── GeneTree_reconciled.nwk
├── species_node_map.tsv
├── gene_id_map.tsv
├── input_species_node_labels.tsv
├── input_gene_node_labels.tsv
├── gene_events.tsv
├── duplications.tsv
├── hog_members.tsv
├── unresolved_genes.tsv
├── inference.json
└── Phylogenetic_Hierarchical_Orthogroups/
    ├── N0.tsv
    ├── N1.tsv
    └── ...
```

`manifest.json` records paths and inference settings in `family_hog_runs`.
Wide HOG tables retain the columns `HOG`, `OG`, `Gene Tree Parent Clade`, and one
column per species. The family is labelled `OG0000000` internally. Numeric
species/gene aliases used by the original algorithm are mapped back to input
IDs in all biological outputs.

`gene_events.tsv` records the final inferred duplication/speciation flag,
species-tree mapping, duplication level, and duplications below each gene-tree
node. `duplications.tsv` records events reported during reconciliation, before
the HOG writer's duplication-level refinement. The two tables document different
stages of the copied algorithm.

Original input labels are retained with their original descendant sets in the
two `input_*_node_labels.tsv` files. A label appears in `species_node_map.tsv`
only when the descendant set is unchanged. Support values are not transferred
onto changed gene-tree splits after reconciliation.

Raw HOG results and the candidate's `clusters.tsv` remain available even when
internal scoring cannot recommend a partition, for example a single HOG.
`selected_clusters.tsv` follows the existing scoring rules. A high score against
the same input gene tree is internal agreement, not independent evidence for
the biological correctness of duplication or orthology assignments.

## Auto comparison and resume

`-M auto` includes `hog-tree` only when `--tree`, `--gene-tree`, `--outgroup`, and
`--target hog` are supplied. Otherwise it records why this method was skipped.
Existing `orthofinder` methods continue to use complete proteomes or imported
whole-proteome HOGs. Other methods that need a rooted species tree should receive
an already rooted input, such as this method's exported species tree.

The HOG worker obeys existing candidate and global time limits. After an
interruption, `--resume` uses a new attempt directory and preserves the previous
diagnostics. Completed HOG outputs are checked by SHA-256 before cache reuse.
Changes to input trees, outgroup, parameters, adapter, or bundled algorithm
invalidate the existing run fingerprint.

## Python interface

```python
from cluster_engine.hog_tree import infer_hogs

result = infer_hogs(
    gene_tree="family.treefile",
    species_tree="species.treefile",
    gene_to_assembly={"a1": "A", "a2": "A", "b1": "B", "o": "O"},
    outgroup="O",
    output_dir="family_hogs",
    hog_level="N1",
    split_paralogous_clades=False,
)
print(result["groups"])
print(result["unsupported"])
```

`groups` contains every target exactly once, including unresolved singletons.
`unsupported` identifies those unresolved targets. The direct function accepts
an optional `check_budget` callback at stage boundaries; the CLI worker provides
process-level timeout enforcement.
